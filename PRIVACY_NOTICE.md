# Privacy Notice — PDPA Audit Bot

## What this tool does
This tool analyses documents for PDPA compliance using Google Gemini AI via Vertex AI.

## Data processing
- Your document is sent to Google Gemini via Vertex AI
- Processing region: Google Cloud Singapore (asia-southeast1)
- Google Cloud stores data only in the specified region
- This tool does not retain your document after analysis

## Reports
- Audit reports are saved locally to the /reports folder
- Reports are automatically deleted after 30 days
- You are responsible for securing your local /reports folder

## No personal data collected
This tool does not collect, store or transmit any personal data about the user. Only the document you submit is processed.

## Data sources
Case precedents cited in audit reports are sourced from publicly 
available PDPC enforcement decisions published at 
https://www.pdpc.gov.sg/enforcement-decisions

This tool does not reproduce full case decisions. Only case 
citations, organisation names, penalty amounts, and breach 
summaries are referenced for educational and compliance 
screening purposes.

## Disclaimer
This tool does not constitute legal advice. Verify all findings with a qualified data protection professional.
